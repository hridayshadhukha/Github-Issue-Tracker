

### Q1. What is the difference between var, let, and const?
A: var, let and const are used for variable declarations. var is the old type, it is function scoped and hoisting, meaning it can be accessed from above, regardless of where it is declared. let is block scoped, so it only works inside the block it is declared in and hoists, but not as undefined. const is also block scoped, but it is a variable whose value cannot be changed. Let and const are used in newer code.


### Q2. What is the spread operator (...)?
A: spread operator (...) is a syntax that is used to spread all the elements of an array or object individually. For example, spread is used to copy an array, combine multiple arrays, or merge the properties of an object.


### Q3. What is the difference between map(), filter(), and forEach()?
A: map(), filter() and forEach() all work on arrays, but their usage is different. For example: 

1.forEach() – runs a function on each element, but does not return anything. It is only used for iteration. 

2.map() – creates a new array by running a function on each element, where each element is the result of the function. The original array remains unchanged. 

3.filter() – examines each element and creates a new array with only those that meet the condition. Here too, the original array remains unchanged.


### Q4. What is an arrow function?
A: An arrow function is a function written in a short syntax. It uses => instead of the normal function keyword. It is usually used to compact code and preserve context.


#### Q5. What are template literals?
A: Template literals are a special type of string that is written with a backtick (`). They allow you to easily use variables, expressions, or multi-line strings. Variables or expressions can be embedded using the ${} syntax.
